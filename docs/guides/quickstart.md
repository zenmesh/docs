# Quickstart

Set up your first webhook with Zen Mesh in 5 minutes.

## Prerequisites

- A Zen Mesh account (Free or Pro plan)
- A provider account (Stripe, GitHub, or custom webhook source)
- An endpoint URL to receive deliveries

## Step 1: Get Your API Key

1. Log in to your Zen Mesh dashboard
2. Navigate to API Keys
3. Create a new key and save it securely

## Step 2: Connect a Provider

1. Navigate to **Providers** → **Add Provider**
2. Select your provider type
3. Enter the webhook signing key from your provider
4. Zen Mesh generates a delivery endpoint URL

## Step 3: Configure a Destination

1. Navigate to **Destinations** → **Add Destination**
2. Enter your endpoint URL
3. Select retry configuration
4. Save

## Step 4: Test

1. Trigger a test event from your provider
2. Verify delivery at your endpoint
3. Check the delivery log in the dashboard
