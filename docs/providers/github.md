# GitHub Provider

> **Status:** Supported at launch — requires runtime proof for full claim scope.

Connect GitHub webhooks to Zen Mesh for reliable delivery.

## Setup

1. In GitHub, navigate to **Settings** → **Webhooks** → **Add webhook**
2. Paste the Zen Mesh delivery endpoint URL
3. Set the content type to `application/json`
4. Select events to watch
5. Copy the GitHub webhook secret into Zen Mesh

## Supported Events

Zen Mesh forwards all GitHub webhook events. Common events include:

- `push`
- `pull_request`
- `issues`
- `star`

## Configuration

- **Webhook Secret:** Required for HMAC signature validation
- **Event Filter:** Optional — select which events to forward
- **Endpoint:** Auto-generated by Zen Mesh
