# Shopify Provider

> **Status:** Launch target — not runtime-proven. Do not claim as live without proof.

Connect Shopify webhooks to Zen Mesh for reliable delivery.

## Planned Setup

1. In Shopify Admin, navigate to **Settings** → **Notifications** → **Webhooks**
2. Create a webhook pointing to your Zen Mesh delivery endpoint
3. Select event topics
4. Copy the Shopify HMAC key into Zen Mesh

## Status

This integration is a launch target. It has not been runtime-proven. Refer to the [Leonardo Decision Queue](../review/docsai023_leonardo_decision_queue) for current status.
