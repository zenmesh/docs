# Custom Provider

> **Status:** Supported at launch.

Connect any HTTP webhook source to Zen Mesh.

## Setup

1. Navigate to **Providers** → **Add Provider** → **Custom**
2. Enter your webhook source URL (if applicable)
3. Configure signing key (HMAC-SHA256 or skip if unsigned)
4. Zen Mesh generates a delivery endpoint URL

## Configuration

- **Signing Key:** Optional — HMAC-SHA256 signature validation
- **Payload Format:** Any JSON
- **Endpoint:** Auto-generated by Zen Mesh

## Use Cases

- Custom application webhooks
- Internal service notifications
- Third-party integrations without native support
