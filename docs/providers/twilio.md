# Twilio Provider

> **Status:** Launch target — not runtime-proven. Do not claim as live without proof.

Connect Twilio webhooks to Zen Mesh for reliable delivery.

## Planned Setup

1. In Twilio Console, configure webhook URLs for voice/SMS events
2. Point webhooks to your Zen Mesh delivery endpoint
3. Configure validation in Zen Mesh

## Status

This integration is a launch target. It has not been runtime-proven. Refer to the [Leonardo Decision Queue](../review/docsai023_leonardo_decision_queue) for current status.
