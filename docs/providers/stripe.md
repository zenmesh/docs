# Stripe Provider

> **Status:** Supported at launch — requires runtime proof for full claim scope.

Connect Stripe webhooks to Zen Mesh for reliable delivery.

## Setup

1. In Stripe, navigate to **Developers** → **Webhooks**
2. Create a new webhook endpoint using the URL from Zen Mesh
3. Select events to forward
4. Copy the Stripe webhook signing key into Zen Mesh

## Supported Events

Zen Mesh forwards all Stripe webhook events. Common events include:

- `payment_intent.succeeded`
- `payment_intent.failed`
- `invoice.paid`
- `customer.created`

## Configuration

- **Signing Key:** Required for signature validation
- **Event Filter:** Optional — select which events to forward
- **Endpoint:** Auto-generated by Zen Mesh
