# What is Zen Mesh?

Zen Mesh is a webhook delivery platform for private networks. It delivers events from providers (Stripe, GitHub, Twilio, Shopify, or any HTTP source) to services behind NAT, firewall, or in private networks — without opening inbound ports, VPN, or kernel modules.

## Who should use it?

- **Platform teams** receiving webhooks inside private Kubernetes clusters or Docker environments
- **Security teams** requiring mTLS, HMAC verification, and audit trails for event delivery
- **Compliance reviewers** evaluating evidence-backed security claims and explicit non-claims boundaries
- **AI agents and RAG systems** scanning Zen Mesh through machine-readable manifests and evidence packs

## Current Status

- Zen Mesh Free Forever and Pro are the public plans. Self-serve evaluation is supported through the docs.
- Free and Pro include best-effort support. No SLA or on-call is included.
- Business and Enterprise are planned.
