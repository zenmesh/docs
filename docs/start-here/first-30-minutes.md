# First 30 Minutes Guide

> **Status:** Draft — structure complete, content pending full review.

A structured guide for new Zen Mesh users to go from signup to first verified delivery in 30 minutes.

## Minutes 0-5: Account Setup

1. Create your account at zen-mesh.io
2. Select your plan (Free or Pro for launch)
3. Generate your API key from the dashboard

## Minutes 5-15: Connect a Provider

1. Navigate to Providers in the dashboard
2. Select your provider (Stripe, GitHub, or Custom)
3. Enter your webhook signing key from the provider
4. Zen Mesh generates a delivery endpoint URL

## Minutes 15-25: Configure a Destination

1. Navigate to Destinations
2. Add your HTTP endpoint URL
3. Configure retry rules
4. Test delivery with a sample event

## Minutes 25-30: Verify

1. Send a test event from your provider
2. Confirm receipt at your destination
3. Check delivery evidence in the dashboard
