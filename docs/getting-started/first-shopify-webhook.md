# Your First Shopify Webhook (Launch Target)

Connect Shopify to Zen Mesh and receive order, product, and customer events.

Shopify sends webhook notifications for store activity — orders created, products updated, customers modified, and more. Zen Mesh will validate Shopify's shared secret at ingestion and route events to your configured destinations.

> Shopify integration is a launch target. This guide describes the intended workflow — connector validation is in progress. The Shopify source type will be selectable in the dashboard once the connector ships.

**Status:** Launch target — not yet available.

## What Shopify Webhooks Provide

| Event Category | Example Topics |
|----------------|---------------|
| **Orders** | `orders/create`, `orders/updated`, `orders/paid`, `orders/fulfilled` |
| **Products** | `products/create`, `products/update`, `products/delete` |
| **Customers** | `customers/create`, `customers/update`, `customers/delete` |
| **Inventory** | `inventory_levels/update`, `fulfillments/create` |
| **Shop** | `shop/update`, `app/uninstalled` |

## Prerequisites

- A [Zen Mesh account](https://zen-mesh.io)
- **Admin access** to a Shopify store
- A [target](./create-first-target) configured and reachable

## Step-by-Step (Planned)

These steps are based on the planned connector behavior and may change during validation.

### 1. Create a Shopify Source

1. In the Zen Mesh dashboard, go to **Sources → Add Source**
2. Enter a name, for example `shopify-prod-orders`
3. Select **Shopify** as the provider type
4. Under **Verification**, configure the Shopify shared secret:

   ```
   verification:
     method: "secret_based"
     secret: "your_shopify_webhook_secret"
     header: "X-Shopify-Hmac-SHA256"
   ```

   The shared secret is generated by Shopify when you create a webhook endpoint in the Shopify Admin.

5. Save the source and copy the ingestion URL

   ```
   https://ingest.zen-mesh.io/hooks/hook_mno456pqr789
   ```

### 2. Create a Target

1. Go to **Targets → Add Target**
2. Enter a name, for example `shopify-order-processor`
3. Enter the URL of your service that will process Shopify events
4. If the service is on a private network, select your connected cluster
5. Click **Save**

### 3. Create a Route

1. Go to **Routes → Add Route**
2. Enter a name, for example `shopify-orders-to-processor`
3. Select the Shopify source
4. Select the target
5. Optionally add filters for specific topics:

   ```yaml
   filters:
     event_types:
       - orders/create
       - orders/updated
       - orders/fulfilled
   ```

6. Click **Save** and toggle the route to **Active**

### 4. Configure Shopify Admin

1. In your Shopify Admin, go to **Settings → Notifications → Webhooks**
2. Click **Create webhook**
3. Paste your Zen Mesh ingestion URL

   ```
   https://ingest.zen-mesh.io/hooks/hook_mno456pqr789
   ```

4. Select the event topic(s) you want to receive (e.g. `orders/create`)
5. Set format to **JSON**
6. Shopify generates a webhook secret — copy this value and paste it into your Zen Mesh source's verification configuration
7. Click **Save**

### 5. Add Labels

```
labels:
  team: commerce
  service: shopify
```
