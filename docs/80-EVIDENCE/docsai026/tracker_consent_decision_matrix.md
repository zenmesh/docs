# Tracker/Consent Decision Matrix

## Recommended V1 Default
- **No heavy trackers** (no Google Analytics, no HubSpot) before legal signoff
- **Self-host fonts** as default
- **Vercel Analytics/Speed Insights** only if Leonardo approves and disclosed
- **No consent management platform** for V1 (overkill without heavy trackers)
- **Email support** (support@zen-mesh.io) as V1 support channel
- **Cookie banner**: minimal notice if no non-essential trackers; full banner only if trackers active

## Options Summary
| Option | Privacy Impact | Growth Value | V1 Recommended |
|---|---|---|---|
| No analytics | Best | None | Safe default |
| Vercel Analytics | Low | Moderate | Yes if approved |
| Vercel Speed Insights | Very Low | Low | Yes if approved |
| Google Analytics | High | High | No before legal |
| HubSpot | High | High | No — V1.1+ |
| Google Fonts (external) | Low | Cosmetic | No — self-host instead |
| Self-hosted fonts | None | Cosmetic | Yes — default |
| Cookie banner | N/A | Compliance only | Minimal notice if no trackers |
| CMP | N/A | Compliance only | Not needed for V1 |
| Support chat/CRM | Varies | Moderate | Email only for V1 |
