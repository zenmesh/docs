# Responsible Disclosure / Security Policy (Draft)

## 1. Contact

**Security contact:** security@zen-mesh.io

## 2. Security.txt

Zen Mesh intends to publish a security.txt file at:

- **Location:** `/.well-known/security.txt`
- **Canonical URL:** `https://zen-mesh.io/.well-known/security.txt`
- **Policy URL:** Security/responsible-disclosure page (this page)
- **Language:** en
- **Expires:** 12 months from intended publication

An optional encryption key may be added pending Leonardo's decision.

## 3. Disclosure Policy

We encourage coordinated disclosure. If you discover a security vulnerability in Zen Mesh:

1. **Report** the vulnerability to security@zen-mesh.io
2. **Do not** publicly disclose the vulnerability before coordinated remediation
3. **Provide** sufficient detail to reproduce the issue
4. **Allow** reasonable time for remediation before public disclosure

## 4. What We Commit To

- Acknowledge receipt of your report
- Investigate the reported issue
- Communicate remediation status

## 5. What We Do Not Commit To

- No bounty program is offered at this time
- No response-time SLA is promised
- No specific remediation timeline is guaranteed

## 6. Out of Scope

The following are not in scope for responsible disclosure:
- Third-party services (Stripe, GitHub, etc.)
- Social engineering
- Denial-of-service attacks
- Physical security
