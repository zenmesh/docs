# WebSocket API

Real-time event streaming is available via the BFF WebSocket endpoint for dashboard consumption.

## Not Yet Documented

The WebSocket API is used internally by the Zen Mesh dashboard for real-time delivery tracking and event streaming. Public WebSocket documentation will be added when the consumer surface is finalized for external use.

See the BFF OpenAPI spec at `src/saas/bff/openapi/zen-bff.v1.yaml` for the Events and Jobs endpoints.
